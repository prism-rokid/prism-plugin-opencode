## 冒烟发现并修复

1. **跨目录会话无法收到事件**：`GET /event` 属于目录级实例，缺少 directory 时，真实模型虽然完成，订阅和 waitForRun 却收不到终态。新增请求 context 的目录作用域，覆盖 Subscribe、WaitForRun、live history 和配置/详情请求；显式 CreateSession directory 保持优先。
2. **流式文本丢失消息关联**：真实 `message.part.updated` 将 messageID 放在 `properties.part.messageID`。补充解析，确保远端输出关联到原生 assistant 消息。
3. **中断被误判成功并回显旧回复**：真实 idle 不一定携带 reason。终态改为结合最新 assistant 的 `info.error`，将 MessageAbortedError 映射为失败/中断；其他原生错误也不再映射为成功。空文本不会继续查找上一轮回复。

新增回归测试覆盖目录参数（含中文/空格/特殊字符）、创建目录优先级、SSE 终态、消息关联、中断和 API 错误。
新增 `conformance/real_smoke.py`，可复用真实 CLI 冒烟，使用方法见 README。
